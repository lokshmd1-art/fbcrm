# CRM «Прозвон»

Настольное приложение (Windows / macOS / Linux) для прозвона баз вебинаров и ведения воронки пресейла.
Сделано на основе кликабельного прототипа `crm-mvp_21.html`: интерфейс тот же, но данные сохраняются на компьютере.

## Как установить

Установщики собираются автоматически на GitHub при каждом пуше. Чтобы скачать:
вкладка **Actions** в репозитории → последний запуск «Сборка приложения» → блок **Artifacts** внизу страницы.

- **Windows:** `crm-prozvon-windows`. Внутри два файла:
  - `CRM Prozvon-…-setup.exe` — обычный установщик;
  - `CRM Prozvon-…-portable.exe` — запускается без установки.

  Приложение не подписано сертификатом, поэтому Windows может показать «Windows защитила ваш компьютер».
  Нажмите «Подробнее» → «Выполнить в любом случае».
- **macOS:** `crm-prozvon-mac`, файл `.dmg`. При первом запуске: правый клик по приложению → «Открыть».

## Где хранятся данные

Файл `crm-data.json` в папке данных приложения. Быстрее всего открыть её через меню **Файл → Открыть папку с данными**.

- Windows: `%APPDATA%\CRM Prozvon\`
- macOS: `~/Library/Application Support/CRM Prozvon/`
- Linux: `~/.config/CRM Prozvon/`

В меню **Файл** есть также:
- «Сохранить резервную копию…» и «Восстановить из резервной копии…»;
- «Сбросить к демо-данным…» — удаляет всё введённое и возвращает демо-данные из прототипа.

## Для разработки

```bash
npm install
npm start           # запустить приложение
npm run dist:win    # собрать под Windows (на Linux нужен Wine)
npm run dist:mac    # собрать под macOS (только на Mac)
```

Структура:

| Файл | Что внутри |
|---|---|
| `app/index.html` | разметка интерфейса |
| `app/styles.css` | стили |
| `app/app.js` | логика интерфейса (из прототипа) |
| `app/demo-data.js` | демо-данные для первого запуска |
| `main.js` | окно приложения, меню, сохранение на диск |
| `preload.js` | мост между интерфейсом и сохранением / буфером обмена |
