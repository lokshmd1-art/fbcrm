# CRM «Прозвон» — контекст проекта

Настольное приложение на Electron для прозвона баз вебинаров (Первый БИТ) и воронки пресейла.
Сделано из кликабельного прототипа `crm-mvp_21.html` (одностраничный HTML): интерфейс перенесён
без изменений, добавлено сохранение данных на диск. Пользователь смотрит на приложение и даёт правки
по интерфейсу — общаемся по-русски.

## Запуск

```bash
npm install
npm start        # режим разработки; после правки в app/* — Ctrl+R в окне приложения
```

Правки в `main.js` / `preload.js` требуют перезапуска `npm start`.

## Структура

- `app/index.html` — разметка (вкладки «Компании», «Воронка», «Пресейл»)
- `app/styles.css` — стили; цвета в CSS-переменных на `:root`, есть тёмная тема
- `app/app.js` — вся логика интерфейса (IIFE, ES5, рендер строками через innerHTML)
- `app/demo-data.js` — демо-данные для первого запуска (`window.CRM_DEMO_DATA`)
- `main.js` — окно, меню «Файл» (резервная копия, восстановление, сброс), запись базы на диск
- `preload.js` — `window.crm`: `load`, `save`, `copyText`, `copyImage`
- `build/icon.png` — иконка приложения

## Данные

- Хранятся в `crm-data.json` в папке userData (`%APPDATA%\CRM Prozvon\` на Windows).
- В базе: `managers`, `bases`, `companies` (со звонками `calls`), `deals` (с `comments`, `tasks`).
- Справочники в коде `app.js`: `callResults`, `STAGES`, `TERMINAL_STAGES`, `AUTO_DEAL_TRIGGERS`, `emptyDirs`.
- Сохранение: `persist()` вызывается в начале `renderAll()` и `renderPresale()` (с задержкой 300 мс).
  Любое изменение данных должно заканчиваться вызовом одной из этих функций, иначе оно не сохранится.
- Если меняется формат данных — учесть, что у пользователя уже есть сохранённая база
  (демо-данные подхватываются только когда файла нет).

## Сборка

- Установщики Windows (setup + portable) и macOS (dmg) собирает GitHub Actions
  (`.github/workflows/build.yml`) при каждом пуше; скачать — Actions → Artifacts.
- Локально: `npm run dist:win` / `npm run dist:mac`.
